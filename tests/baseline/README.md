# TS baseline (historical)

These artifacts were generated with the TypeScript implementation before the `v0.1-ts` cut.
They are kept only to verify that the schemas of `checks.json`, `verdict.json`, `ledger.jsonl`
and the verifier prompt did not change during the migration.

They are not active code and do not run in the suite. The references to `npm` and `.ts` that
appear in these files are part of the historical fixture.
